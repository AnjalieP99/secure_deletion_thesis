# Thesis_Secure_Deletion
# Secure Deletion Techniques Evaluation Framework

A Master's Thesis Project on Digital Forensics and Anti-Forensics

## Project Overview

This research aims to create an experimental framework for evaluating secure deletion techniques across various storage media and environments, with particular focus on flash memory and containerized systems.

## Research Objectives

- Develop reproducible testing methodology for secure deletion tools
- Evaluate effectiveness of deletion techniques on SSDs/flash memory
- Analyze secure deletion in containerized environments (Docker/Kubernetes)
- Investigate legal and ethical implications of anti-forensic tools
- Develop forensic indicators for secure deletion activities
